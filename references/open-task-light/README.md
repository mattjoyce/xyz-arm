Open Task Light carriage reference
=================================

Author: Steven Bennett. Original licence retained in `LICENSE`.

Source: https://github.com/stevenbennett/Open-Task-Light/blob/main/Open%20Task%20Light/Printed%20Parts/STL/Carriage/carriage-body_v1.1.stl

Downloaded 2026-09-12 from main. The STL is unmodified. Mesh bounds are X/Y −42.083332 to +42.083332, Z 0 to 7.800000: approximately 84.17 × 84.17 × 7.8 mm, assuming the project's millimetre units. It contains 4,262 triangles.

Open `../../cad/studies/carriage-study.scad` for a standalone view. The body has been visually inspected and rendered in `../../cad/previews/carriage-study.png`. The original mesh remains a reference. `../../cad/xyz-arm.scad` uses a separate parametric compact carriage with three wheels per axis and 60 mm longitudinal wheel spacing. The clip is omitted.
